# My library-web development 1 project 
A responsive library web application as part of the web development 1 coursework.
## features
- ** library design:** clean layout with custom color theme
- ** interactive features:** Dark Mode toggle and book favorite system using javascript
- ** responsive layout :**optimized for both desktop and mobile devices using CSS Media Queries
